# 18004 文本动作召回评测（2026-09-18）

## 结论

本次使用 238 条纯文本用例，每条用例建立独立 Session，避免跨 turn 历史动作影响。
18004 服务全程健康，238/238 turn 完成，运行错误为 0。

身体动作的主要问题是 Top-1 排序，不是完全没有召回正确候选：

- 200 条明确身体动作请求（排除 16 条基础表情）中，Top-1 为 49/200（24.5%）。
- 正确候选进入 Top-3 为 128/200（64.0%），进入 Top-5 为 194/200（97.0%）。
- 151 条身体动作 Top-1 错误中，70 条被 `UNSUPPORTED` 抢占，55 条被 130“自然呼吸起伏”抢占，10 条被 135“连续摇头”抢占；三者合计 135/151（89.4%）。
- 因此当前最主要的问题是少数候选的高先验和缺少候选校准/语义约束，而不是目录动作不可识别。

基础表情需要走 `expression+action` 输出。补充评测的 16 条 category 19 用例全部选中正确 candidate；其中 12 条可执行，害怕、悲伤、疑惑、生气 4 条虽然语义选择正确，但被下游标为不可执行。

## 环境与方法

- 服务：`ws://127.0.0.1:18004/v1/session/realtime`
- 模型：`qwen3-omni-single-gpu`
- 服务目录：25 类、117 个动作
- 服务目录 hash：`sha256:3025384e63dc4819ed08038fdcaadbe27ba3f3f8e12f9813dad131445871de57`
- 输入：仅文本，无音频、图片、avatar state 或历史 turn
- 隔离：每个 case 使用独立 Session
- 并发：2；遇到 `session_busy` 自动等待并重试
- 主评测输出：`action`
- 表情补充评测输出：`expression+action`
- 每轮开启完整 action scores，保存 Top-10 排名

本评测的延迟是两个独立 Session 并发时从发送 `turn.commit` 到收到 `turn.result` 的客户端时间，
不能作为单会话延迟基线。

以下结果排除了 category 19 基础表情。自然请求中有一条“保持自然呼吸”在评分前被判为
`body_not_requested`，因此自然请求共有 91 条，但只有 90 条产生完整候选排名。

| 分组 | 数量 | Top-1 | Top-3 | Top-5 |
| --- | ---: | ---: | ---: | ---: |
| 目录名称请求 | 109 | 25（22.9%） | 71（65.1%） | 107（98.2%） |
| 自然表达 | 91 | 24（26.4%） | 57（62.6%） | 87（95.6%） |
| **合计** | **200** | **49（24.5%）** | **128（64.0%）** | **194（97.0%）** |

动作排名反推，不能代替独立 category scorer 的正式 A/B 结果。

## 排名偏置

在所有有明确 candidate 期望但 Top-1 错误的样本中，最常见错误选择为：

| 错误 Top-1 | 次数 |
| --- | ---: |
| `UNSUPPORTED` | 70 |
| 130 自然呼吸起伏 | 64 |
| 135 连续摇头 | 11 |
| 199 单臂伸向右侧 | 4 |
| 197 单臂伸向前方 | 3 |
| 138 看镜头 | 3 |

以已知“请求一定受支持”的离线样本做诊断，如果临时从排名中移除 130、135 和
`UNSUPPORTED`，目录名称请求 Top-1 可由 22.9% 升至 86.2%，自然表达由 26.7% 升至
82.2%。这不是可直接上线的过滤规则，因为 130、135 和 `UNSUPPORTED` 本身都有合法场景；
它只证明候选先验校准、类别约束和明确动作直达值得优先实施。

## 优化优先级

1. 为候选 ID 做 neutral-baseline/PMI 校准，重点观察 130、135 和 `UNSUPPORTED` 的全局先验。
2. 对明确身体动作使用 decision gate 做一致性约束：`body=perform` 时不得由待机动作替代；
   但仍应保留真正不支持动作的拒绝能力。
3. direct 模式接入经过审核且无冲突的 action aliases，使“点赞、双手比心、数字手势”等明确
   请求可缩小到唯一候选。
4. 在同一物理 batch 中增加独立 category label，使用高置信 Top-1 或低置信 Top-2/Top-3
   类别约束具体动作；本次正确类别 Top-3 覆盖约 95%。
5. 单独修复 speech-only 边界，尤其是“说二比一”，避免语音内容中的数字和否定语义触发身体动作。
6. 将基础表情的语义召回与执行能力分别监控，避免把 16/16 的正确选择误报成 12/16 的识别率。
